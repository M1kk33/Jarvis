# M9 create-only text files

Start a model-backed browser session with an explicit `--write-root` pointing to an existing local fixed-drive directory. This grant is separate from `--read-root` and is available only to the browser approval flow. No terminal auto-approval is provided. The destination must be an absolute `.txt` path under the grant, with existing ordinary directories and no traversal, reparse points, hard links, alternate data streams, reserved or sensitive names, or private Jarvis state. Content is UTF-8 text up to 8 KiB; hidden formatting controls are rejected so the approval preview remains legible. The tool never edits, deletes, creates directories, or overwrites a file.

The browser previews the exact new path and full text. Approval is tied to the turn, job attempt, invocation, canonical arguments, policy, and destination-parent identity and modification state. A changed destination invalidates approval. After the single-use approval and durable execution intent, Jarvis holds checked directory handles without delete sharing, creates the file exclusively, flushes and verifies its bytes, and records a content-hash receipt. Cancellation after creation retains the completed effect in conversation context.

A crash between creation and the SQLite receipt leaves `outcome_unknown` and blocks automatic replay. In the browser, **Verify file** checks whether the exact expected path under the original parent now contains the exact approved bytes; the CLI `reconcile-file INVOCATION_ID` command performs the same check with an explicit `--write-root`. A match records the verified result without writing again. Missing, changed, or unverified files remain unresolved for manual inspection. After a successful reconciliation, an interrupted job can be explicitly resumed to produce its final chat reply. Restart before approval or before the action writes nothing and never revives an old approval.

Jarvis backups retain the conversation and receipt, but an external file under a write root is not an app artifact. Back up that directory separately.
